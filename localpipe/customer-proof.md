# LocalPipe customer proof

These reviews are published on the LocalPipe homepage, which also links to Trustpilot. Quote them as written and attribute them by the name shown. The two-letter code after each name is the location code displayed beside the review. Do not merge two reviews into one quote or attach a result to a different customer.

## Headline numbers

- **34,700,000+** emails sent by users on LocalPipe data
- **Sub 1%** bounce reported in live campaigns, **0.11%** in one documented case (InterCo Digital)
- **7%** reply rate reported by one user (Jason Park)
- **+33%** positive reply rate and **+20%** TAM reported by one agency (Lars Matthys)
- **70%** coverage on a list, about **87%** once businesses with no website are removed (InterCo Digital)
